XZoom 是适用于 X（Twitter／推特）的图片放大与原图下载插件。在帖子看图窗口里滚轮缩放、拖动查看长图，或按 1:1 看清实际像素。

放大图片，看清长图与细节
• 鼠标滚轮或 + / − 按钮缩放，最高放大至 800%。
• 围绕看图区域中心缩放，不受鼠标位置影响。
• 放大后拖动查看；适应窗口可看完整图片，1:1 可看实际像素。
• 双击切换适应窗口与原始尺寸。控件获得焦点后，可用 + / − 缩放、0 恢复适应窗口。

推特原图下载
打开帖子图片时自动请求 X 当前可用的原图，加载后点击下载即可保存。加载失败时仍可查看预览图，并手动重试。
“原图”指 X 当前提供的最大图片版本，不保证是上传前的相机文件；部分预览本身已与原图同尺寸。缩放不会补出源图缺失的细节。

使用方法
1. 打开 x.com 或 twitter.com，点击帖子图片。
2. 滚轮放大，拖动查看细节。
3. 按需选择适应窗口、1:1 或下载。

免费开源，无追踪
无需额外账号或 AI 服务，不含插件统计或后台服务。只在本地处理当前图片和媒体地址，图片请求发往 X 图片 CDN，不向 GoodExts 或 AI 服务发送图片。

保留 X 原生关闭、图片切换和帖子详情。仅处理帖子看图窗口，不处理视频、头像、信息流缩略图或批量下载。
支持英语、简体中文、巴西葡萄牙语与西班牙语，跟随 Chrome 语言。
