# XZoom独立插件与安装验收

创建时间：2026-11-01 13:26，Asia/Shanghai。版本1.0.0。

## 范围

从XFollower4.15.0已验收的图片预览能力提取，改为独立ManifestV3插件。用户明确要求从XFollower移除，后续仅由XZoom维护。目录E:/WebstormProjects/XZoom 插件，GitHub仓库xzoom；源码src，浏览器加载dist，现成ZIP根目录直接包含manifest.json。

## 复用和隔离

沿用MIT许可的@panzoom/panzoom4.6.2，原样从固定npm依赖构建，保留许可。运行时无XFollower桥接、后台、账号数据、存储、AI、统计与追踪。只在x.com与twitter.com注入；打开原生帖子图片预览时请求pbs.twimg.com原图，credentials omit。加载失败保留预览、人工重试；切图取消旧请求，关闭清理。

Chrome内置i18n提供四语言，工具栏在预览中心缩放，最高800%。1:1顶端阅读长图，拖动和适应窗口可用，下载Blob保留40秒再释放，避免切图取消下载。

## 验收

8项Node测试通过，涵盖HTTPS媒体地址、路由、缩放数学、空加载状态、独立权限、语言目录和无桥接依赖。Chrome实际通过Extensions.loadUnpacked加载独立dist，无注入替代；桌面1366和窄屏390，鼠标左右两侧缩放中心误差小于1像素，原生关闭命中。1000×4000实际像素、拖动-100像素、下载252552字节与原图逐字节相同、失败不循环重试、切图和关闭清理通过。可用npm run test:browser重现。

截图在干净测试profile生成：Chrome真实扩展管理页；看图控件为真实插件在可控示例页面运行，明确标注示例，不公开真实账号。Logo由OpenAI内置图像生成工具生成，design/logo.png保留，构建生成16/32/48/128PNG。提示为深蓝底、蓝色放大镜、白色加号与取景四角，避免X商标和文字。

## 安装和限制

现阶段开发者模式安装；ZIP可直接解压加载，GitHub源码ZIP选择其中dist。不是商店发行，不自动更新。只增强原生帖子图片预览，不处理视频、头像或信息流缩略图。原图为X当前name=orig响应，并非上传前相机文件；不承诺额外像素或清晰度。

## 公开交付

用户授权公开GitHub开发仓库及GoodExts介绍。仅发布XZoom代码、构建及本功能文档，不发布XFollower源码、数据库或登录profile。GoodExts使用原有四语言博客组件、原有统计同意设置及main分支Cloudflare集成，不新建子站、GA账号、OAuth或外部目录投放。最终公开地址与提交在交付时核验。

### 四语言补充验收

Chrome分别以en-US、zh-CN、pt-BR、es-419启动，使用真实加载的独立扩展分别完成桌面及窄屏的中心缩放、1:1、拖动、下载、错误重试、切图与清理。弹窗、工具栏和指南链接跟随语言，无宽度溢出。
